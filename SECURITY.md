# Security

## Supported versions

Security and correctness fixes are provided for the latest published minor
version. Upgrade before reporting behavior against an older release.

## Reporting

Please use GitHub's private vulnerability-reporting flow under the repository's
Security tab. Do not open a public issue containing an undisclosed
vulnerability, private key, provider credential, or sensitive transaction
detail.

This package contains read-only configuration and data helpers. It does not
sign or submit transactions. Independently verify contract addresses and
network state before moving value.
