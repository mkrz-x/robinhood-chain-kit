# Add Oracle Guard

**Goal:** Add a dependency-free, fail-closed Oracle Guard API that turns Robinhood Chain feed metadata and round data into exact prices and explicit usability diagnostics.
**Why planning is required:** This introduces public SDK contracts for price safety, directory parsing, sequencer state, and corporate-action pause handling, and it coordinates release hardening across runtime and CI tooling.
**Acceptance:** Callers can validate and load the live feed directory, format signed bigint answers exactly, and assess every supplied round without silently treating unknown sequencer or pause state as usable; retained tests cover schema drift and each safety state; package, example, exact-runtime, live-canary, and tarball import/require checks pass.

### Outcome 1: Typed feed directory
- Work: Replace the URL-only feed surface with a normalized feed metadata type, strict runtime parser, retrying loader with injection and cancellation, address lookup, and Chainlink Aggregator V3 ABI constants. Reject malformed directories atomically rather than returning partially trusted data.
- Risks/open questions: The upstream directory is an external schema; expose a stable subset and keep unknown fields out of the public contract.
- Verify: `npm test -- src/feeds.test.ts`

### Outcome 2: Exact price and fail-closed health assessment
- Work: Add exact decimal-string formatting and a pure assessment API for positive answers, round timestamps, heartbeat freshness, sequencer availability/recovery grace, and explicit corporate-action pause state. Return all detected issues and never infer pause state or a trading decision.
- Verify: `npm test -- src/feeds.test.ts`

### Outcome 3: Retrying-body and release hardening
- Work: Add a per-attempt body factory for one-shot retryable request bodies and reject unreplayable stream retries; make live canaries validate API response shapes with bounded request time and retries; execute ESM import and CommonJS require from a clean packed-tarball installation.
- Verify: `npm test -- src/retryfetch.test.ts && npm run check:package`

### Outcome 4: v0.5.0 integration and documentation
- Work: Add an Oracle Guard example, update the package surface, README, architecture, changelog, and package version, and preserve the zero-runtime-dependency and client-neutral boundaries.
- Verify: `npm run check:examples && npm run verify`

### Outcome 5: Final evidence and review
- Work: Compare the complete stacked diff with this plan, verify the exact Node 20.3 floor and live data sources, audit dependencies, and obtain an independent whole-feature review.
- Verify: `npm run verify && npm run check:live && npm audit --audit-level=low && git diff --check`
